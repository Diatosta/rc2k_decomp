# rc2k_decomp

A Rust reimplementation of *Rally Championship 2000* (`RAL.EXE`), converted one function
at a time and checked against the original as it went. It now runs as a standalone
program (`rc2k.exe`, SDL3) with no part of the original's code.

## Pages

- [Fixed bugs](Fixed-bugs): the original game's bugs fixed in the Rust version: what each
  one was, what it did in the game, and how it was fixed.
