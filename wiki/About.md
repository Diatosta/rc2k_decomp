# About the project

*Category: [Home](Home)*

The project reimplements *Rally Championship 2000* in Rust, as a program that runs on the
player's own copy of the game's files. The aim is the same game for the player (menus,
physics, stages, replays, save files) on today's systems, with the original's bugs fixed. It is
maintained by Diatosta and was written with the help of AI coding assistants; the
repository's README has the credits and the licence.
